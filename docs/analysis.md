# 华为五看三定分析--learngit59

## 五看
1.**看行业趋势**
Git 与开源协作已经成为软件开发行业基础能力，国内高校陆续开设开源文化相关课程；开源协作、版本控制已经是程序员必备技能，小型示范仓库适合新手理解完整开源流程。

2. **看市场客户**
目标使用者为本班选修《开源文化运动》的同学，以及想要入门Git的初学者。大家需要一个完整、简洁的样板仓库，直观看到许可证、分支管理、冲突解决、Issue协作全套流程。

3. **看竞争**
GitHub上存在大量Git教程仓库，但大多偏向文字教程。本仓库优势：麻雀虽小五脏俱全，是可复现的实战样例；短板：功能少，定位是课程实践仓库，不是大型工具。

4. **看自己**
本仓库由在校学生维护，首要目标是完成课程考核；能够熟练完成提交、新建分支、合并、解决冲突；精力有限，不做大规模开发，优先保证开源规范齐全。

5. **看机会**
可以作为班级内部的Git示范仓库，后续持续补充Git命令笔记，方便同班同学参考学习，也方便后续拓展更多开源实践内容。

## 三定
1. **定战略控制点**
守住-开源课程实战样板-定位，保证许可证、文档、分支流程、Issue协作全部规范完整，不堆砌无关内容，保持仓库干净。
2. **定目标**
短期目标：完成课程全部考核项，实现多分支、冲突合并、Issue互动；长期目标：成为一份可复用的校内Git入门示范仓库。
3. **定策略**
遵循Git Flow；新增内容走独立功能分支；利用Issue收集反馈；文档优先，降低其他同学上手学习的门槛。
