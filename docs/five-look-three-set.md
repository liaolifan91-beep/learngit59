# 华为五看三定 —— 本项目分析
## 五看
### 看行业 / 趋势
开源已经成为软件协作主流，Git + GitHub 是开源协作的标准工具。版本控制、分支协同、开源协议是开源入门必备能力，高校开源课程也在推广这套实践。

### 看市场 / 客户
面向课程考核，目标“客户”是授课老师；同时面向初学开源的同学，可以作为一份可参考的 Git 实操示范仓库。

### 看竞争
网上虽然有大量 Git 教程，但大多零散；本仓库是一套完整、连贯、可复现的实操案例，从建库、分支、冲突到开源文档全部打通。

### 看自己
自身掌握基础 Git 命令，能够完成仓库搭建、分支创建、冲突处理；短板在于大型开源项目协作经验不足。

### 看机会
这个仓库可以持续维护，后续补充更多 Git 进阶示例，供同班同学参考，形成小型共享学习仓库。

## 三定
### 定战略控制点
保证仓库流程完整规范：许可证、说明文档、分支流程、冲突演示、Issue 协作全部落地，满足课程全部考核点。

### 定目标
完成课程期末考核；产出一份干净、可复现的 Git 开源示范仓库。

### 定策略
1. 使用 Git 分支模型，区分稳定主线与开发分支；
2. 保留完整操作痕迹，所有操作留存截图；
3. 发起协作互动：邀请同学 Issue 讨论、Star、Watch；
4. 补齐规范文档，遵循开源基础规范。
