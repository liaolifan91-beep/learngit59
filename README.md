# learngit59
开源文化运动期末作业仓库

## 项目简介
本仓库为《开源文化运动》课程期末作业，用于演示 Git 版本控制、分支开发、分支合并与冲突解决。

- 主分支：`master`，保存稳定版本
- 开发分支：`dev`，用于功能迭代
- 许可证：MIT License
- 文档：
  - `docs/five-look-three-set.md`：华为五看三定项目战略分析
  - `CONTRIBUTING.md`：贡献指引

## 操作说明
本仓库完整复现：仓库初始化、远程绑定、分支创建、分叉提交、制造合并冲突、手动解决冲突、远程推送整套 Git 流程。
欢迎提 Issue 交流、Star & Watch。
